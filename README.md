## Overview

Engineering Quotation Tool combines engineering project organization with quotation preparation in a web application. It gives users a consistent place to examine project information and develop estimated costs for a quotation.

The application is aimed at anyone who needs a simple browser workflow for assessing engineering requirements and building project estimates. Since it runs on the web, it does not require installation of a desktop program tied to a particular operating system.

The application can be used in the following sequence:

1. Start the tool in a web browser.
2. Add or inspect the engineering project data.
3. Structure the project information and quotation inputs.
